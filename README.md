# Novex Agro

A modern web application built with React, TypeScript, and Vite, featuring a stylish UI and Supabase integration.

## 🚀 Technologies Used

- **Frontend Framework:** React 18
- **Build Tool:** Vite
- **Language:** TypeScript
- **Styling:** Tailwind CSS & Autoprefixer
- **UI Components:** 
  - `@headlessui/react` for accessible components
  - `lucide-react` for beautiful icons
  - `motion` (Framer Motion) for fluid animations
- **Routing:** React Router v7
- **Backend & Auth:** Supabase

## 📦 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (v18 or higher) installed on your system.

### Installation

1. Clone the repository (if applicable) and navigate to the project directory:
   ```bash
   cd novex-agro
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

### Development

To start the development server with Hot Module Replacement (HMR):

```bash
npm run dev
```

### Building for Production

To create a production-ready build:

```bash
npm run build
```

You can preview the built application locally using:

```bash
npm run preview
```

## 🛠️ Scripts

- `npm run dev` - Starts the Vite development server.
- `npm run build` - Builds the application for production.
- `npm run lint` - Runs ESLint to check for code quality and style issues.
- `npm run typecheck` - Validates TypeScript types without emitting compiled files.
- `npm run preview` - Previews the production build locally.

## 📁 Project Structure

This project follows a standard Vite + React setup:
- `src/` - Application source code.
- `public/` - Static assets that are copied directly to the build folder.
- `index.html` - The main entry point of the application.
- `vite.config.ts` - Vite configuration file.
- `tailwind.config.js` - Tailwind CSS configuration file.
